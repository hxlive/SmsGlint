# SmsGlint ⚡

> **轻量、灵动的 Windows 桌面短信验证码接收与自动复制助手**  
> 配合安卓端 [SmsForwarder (短信转发器)](https://github.com/pppscn/SmsForwarder) 使用，通过 MQTT 协议将手机短信秒级投递到电脑桌面，智能提取验证码、灵动气泡弹窗，并支持自动同步至剪贴板。

## ✨ 核心特性

- 🚀 **即时无感投递**：基于 MQTT 协议（支持 TLS 加密端口 8883），跨网络、跨局域网秒级投递，不依赖手机电脑在同一 WiFi。
- 🎨 **灵动滑入气泡**：右下角半透明悬浮卡片平滑滑入，8 秒无操作自动滑出淡出；完美适配 **4K / 高 DPI 缩放**（125%、150%、200% 等），不遮挡任务栏。
- 📋 **可选自动复制**：支持自动写入 Windows 剪贴板，收到验证码直接 `Ctrl + V` 完成验证；亦可在配置中关闭，仅保留纯弹窗提醒。
- 🔍 **智能精准提取**：支持 **4 ~ 6 位** 动态验证码识别，针对包含多个数字的短信自动进行语义上下文分析（关键词优先匹配），避免误提取手机号或快递单号。
- 🛠️ **完整 GUI 配置**：无需手动改写 JSON 文件，首次启动自动引导配置，支持可视化一键测试 MQTT 连通性。
- 🔄 **事件驱动断线自愈**：底层网络事件驱动自动重连，正常运行时 **0 额外 CPU/资源开销**，同时托盘支持手动一键重连。
- 📦 **极致精简打包**：独立单文件 EXE 仅 **11.6 MB**，内存占用极低，绿色免安装解压即用。
- 🔒 **单实例保护**：内置进程互斥锁，防止多开造成消息重复消费或冲突。

## 🏗️ 工作原理

```text
  [📱 安卓手机 (收到短信)]
            │
            ▼ (提取短信内容)
   [SmsForwarder 短信转发器]
            │
            ▼ (Webhook API / MQTT 客户端推送)
  [☁️ EMQX Serverless MQTT 服务端 (免费免运维)]
            │
            ▼ (TLS 8883 加密订阅推送)
   [💻 PC 桌面: SmsGlint]
            │
    ┌───────┴──────────────────┐
    ▼                          ▼
[🎯 提取 4~6位验证码]      [📋 同步剪贴板 (可选)]
    │
    ▼
[🎨 右下角灵动滑入气泡弹窗 (8秒自动淡出)]
```

## 🚀 快速上手

### 方式一：直接运行独立 EXE（推荐）
1. 前往 Release 或项目 `dist/` 目录下载最新的 **`SmsGlint_v1.0.exe`**。
2. 双击运行即可。首次运行会自动弹出配置窗口，填写 MQTT 连接信息并保存。
3. 托盘图标将常驻在右下角任务栏。

### 方式二：Python 源码运行
1. 克隆或下载本项目源码。
2. 运行环境要求：`Python 3.10+`。
3. 双击运行 `SmsGlint.pyw`（无黑框运行）或在终端执行：
   ```bash
   python main.py
   ```
   > 项目启动时会自动检测并安装缺失的运行依赖（`customtkinter`, `paho-mqtt`, `pystray`, `pyperclip`, `Pillow`）。

## ⚙️ 服务端与安卓端配置指引

### 1. 准备 MQTT 服务端
推荐使用 **[EMQX Serverless Cloud](https://cloud.emqx.com/)**（免费额度每月提供 100 万连接分钟和 1GB 流量，个人使用完全免费且免运维）：
1. 注册并创建一个免费的 Serverless 部署。
2. 在控制台的【认证鉴权】中添加一个客户端用户名和密码。
3. 获取连接地址（Host）和端口（默认 `8883` 开启 TLS 加密）。

---

### 2. 安卓手机端配置 (SmsForwarder)
在安卓手机上安装 **[SmsForwarder](https://github.com/pppscn/SmsForwarder)**：

#### ① 添加发送通道（推荐 Webhook 或 MQTT）
以 **Webhook** 方式推送到 EMQX HTTP 接口（或直接使用 MQTT 客户端通道）为例：
- **通道类型**：`Webhook` 或 `MQTT`
- **Topic (主题)**：`sms/verify_code`（需与 SmsGlint 中设置的主题一致）
- **推送数据格式**（JSON 格式）：
  ```json
  {
    "device_id": "[extra_device_mark]",
    "sender": "[from]",
    "content": "[msg]"
  }
  ```

#### ② 添加转发规则
- **规则类型**：短信
- **匹配模式**：全部匹配 或 包含关键词（如“验证码”、“校验码”、“code”等）
- **发送通道**：勾选上一步创建的通道

---

### 3. PC 端 (SmsGlint) 配置

首次启动程序会自动弹出配置界面（或随时右键系统托盘图标 -> **MQTT 配置**）：

| 配置项 | 说明 | 示例 / 默认值 |
| :--- | :--- | :--- |
| **服务器地址 (Host)** | EMQX 提供的集群连接地址 | `xxxxxx.emqxsl.cn` |
| **端口** | 默认 TLS 加密端口为 8883，普通为 1883 | `8883` |
| **用户名** | MQTT 鉴权用户名 | `your_username` |
| **密码** | MQTT 鉴权密码 | `your_password` |
| **订阅主题 (Topic)** | 接收短信的主题（需与手机端一致） | `sms/verify_code` |
| **自动复制验证码** | 收到验证码时自动写入剪贴板（可选开关） | `开启 (默认)` |

点击 **【测试连接】** 确认提示“连接成功”后，点击 **【保存】** 即可。

## 📝 配置文件说明

SmsGlint 会在程序同级目录下自动维护 `config.json` 配置文件：

```json
{
  "host": "xxxxxx.emqxsl.cn",
  "port": 8883,
  "username": "your_username",
  "password": "your_password",
  "topic": "sms/verify_code",
  "auto_copy": true
}
```

右键系统托盘图标可使用以下功能：
- **重新连接**：手动触发 MQTT 快速回连。

- **查看日志**：打开实时运行日志窗口，查看消息接收与连接状态。
- **退出**：安全退出并释放后台资源。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 如何设置开机自启动？</b></summary>
按下 <code>Win + R</code> 打开运行窗口，输入 <code>shell:startup</code> 并回车打开系统启动文件夹。将 <code>SmsGlint_v1.0.exe</code>（或其快捷方式）复制到该文件夹中即可。
</details>

<details>
<summary><b>Q2: 为什么有时短信里有多个数字能精准提取到验证码？</b></summary>
SmsGlint 采用了双重匹配策略：首先扫描所有 4~6 位的独立数字；当短信中包含多个数字时，结合“验证码 / 校验码 / code / 是 / 为”等前后上下文关键词进行加权识别，确保提取准确。
</details>

<details>
<summary><b>Q3: 关闭【自动复制验证码到剪切板】后如何使用？</b></summary>
当您关闭该选项时，收到短信只会弹出气泡提醒，不会覆盖您当前的剪贴板内容。如果此时需要复制，只需鼠标点击弹出的气泡卡片，即可主动复制并关闭卡片。
</details>
